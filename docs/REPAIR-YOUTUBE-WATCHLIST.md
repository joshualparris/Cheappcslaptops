# Dead → Alive: Elite Tech Repair YouTube Watchlist

**Curated:** 1 October 2026  
**Purpose:** DadLAN / refurb learning — watch genuinely difficult repairs where broken electronics are diagnosed and brought back to working condition.

## How this is ranked

This is not a claim that one creator is objectively "the best". For each creator, **#1 is the strongest dead-to-alive transformation I found**, then the list steps down from there.

I weighted:
1. how dead/damaged the device was at the start;
2. diagnosis difficulty;
3. board-level / microsoldering / BGA / trace-repair depth;
4. how complete the successful recovery was; and
5. how much the video actually shows the repair process.

Simple battery, screen and module swaps are deliberately down-ranked when that creator has deeper repairs available.

## DadLAN learning order

For **old DadLAN laptops and desktops**, the most transferable channels from this list are:

- **Electronics Repair School** — dead laptop/no-power logic and power rails.
- **NorthridgeFix** — microscope work, trace damage and board repair.
- **Mend It Mark** — disciplined fault-finding when documentation/parts are poor.
- **Louis Rossmann** — excellent logic-board diagnostic reasoning.
- **Hugh Jeffreys** — teardown, cleaning, parts sourcing and making the finished machine presentable again.

For **advanced GPU/BGA work**, start with **Northwest Repair**.  
For **console repair**, use **TheCod3r + TronicsFix**.  
For **microsoldering/data recovery**, use **iPad Rehab**.

## Scope note

This is a learning/watchlist, not an instruction to attempt mains-voltage, battery, BGA or microsoldering repairs without the appropriate equipment and experience. Rankings are editorial and based on the severity + repair-depth + outcome criteria above, not creator popularity.
