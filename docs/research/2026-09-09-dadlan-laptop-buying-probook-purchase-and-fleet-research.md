- tested B/C-grade ex-business stock

The NSW Device Bank / community distribution pathway through WorkVentures was also identified as potentially useful where eligibility/partnering requirements can be met.

## 10. Deep-research conclusions preserved from the report

The deep research produced a 30-page PDF in ChatGPT and these durable conclusions were retained.

### HP ProBook 11 G2 technical conclusions

HP's April 2016 service documentation confirmed the i3-6100U model family with:

- Intel Core i3-6100U
- Intel HD Graphics 520
- 11.6-inch 1366x768 display
- built-in 10/100/1000 Gigabit Ethernet
- three USB 3.0 ports
- HDMI 1.4
- HP 4.5mm Smart power connector
- M.2 2280 SATA storage support

### RAM

For the researched ProBook 11 G2 configuration:

- one customer-accessible SODIMM slot
- DDR4-2133
- HP officially documented 4GB and 8GB configurations
- 8GB was the supported maximum found in HP documentation
- no dual-channel because there is only one slot
- recommended upgrade: replace the 4GB module with one 8GB DDR4-2133 / PC4-17000 260-pin 1.2V non-ECC SODIMM
- do not assume 16GB without stronger model-specific evidence

### Storage

HP documentation supported:

- M.2 2280 SATA-3 SSD
- 128GB / 256GB validated configurations
- SATA M.2, not NVMe
- some chassis/configurations also supported 2.5-inch 7mm SATA hardware depending on installed brackets/cabling

### Battery and charger

Battery parts identified:

- 36Wh 3-cell HP 797429-001
- 64Wh 6-cell HP 797430-001

Power adapters:

- 45W HP Smart 741727-001
- 65W 714657-001
- 19.5V
- 4.5mm HP barrel connector

### CPU and Windows

i3-6100U:

- 6th-gen Skylake
- 2 cores / 4 threads
- 2.3GHz
- 15W
- Q3 2015 Intel launch generation

Windows 11:

- i3-6100U is not on Microsoft's officially supported Intel CPU list for Windows 11
- the seller-installed Windows 11 therefore relies on unsupported-hardware installation behaviour
- this does not make the laptop unsuitable for DadLAN, but it should not be treated as an officially supported Windows 11 machine

Windows 10:

- normal Windows 10 support ended 14 October 2025
- ESU eligibility should be checked per device rather than assumed

## 12. Inventory issue flagged for physical verification

The Toshiba Satellite L850D was flagged for a physical check.

Australian L850D/A10-4600M documentation can include:

- Radeon HD 7660G integrated graphics
- Radeon HD 7610M discrete graphics
- Dual Graphics configuration
- 10/100 Ethernet

Josh's inventory at the time only recorded the HD 7660G.

Action:

- verify the exact GPU configuration using Device Manager / GPU-Z
- do not assume the discrete HD 7610M is installed/enabled until checked

## 13. Revised DadLAN hardware standards

The research concluded that the donor standard should stay deliberately broad and easy to understand.

### Donor-facing minimum

Roughly:

- 2012-era or newer
- Intel Core i3/i5 2nd Gen or better, or similar AMD
- 4GB RAM minimum
- Intel HD 3000-class graphics or better
- must be working

The year should be treated as a rough era guide rather than an absolute technical rule because:

- some useful Sandy Bridge machines are 2011-era
- some much newer Pentium/Atom-derived machines are still too weak

### Paid-purchase target

For machines DadLAN is actually spending money on, the recommended bar should be stricter:

- 6th-gen Core i3/i5 or better
- 8GB RAM preferred
- Intel HD 520/620-class graphics or better
- 120GB+ SSD
- Gigabit Ethernet
- charger
- tested working
- returnable / seller-backed where possible
- target no more than about AU$100 delivered

### HP ProBook 11 G2 pricing rule

For another 4GB/128GB ProBook 11 G2:

- attractive at AU$90 delivered or less
- hard ceiling roughly AU$100 if condition/warranty are good
- prefer an 8GB version at around AU$105 delivered or less if only slightly dearer

## 14. Standardisation and LAN setup conclusions

Recommended fleet-management approach:

- DHCP clients
- simple predictable hostnames such as `DADLAN-L01`
- separate non-admin DadLAN user
- protected admin account
- patch machines roughly one week before an event
- avoid unnecessary changes in the final 48 hours
- use Steam Local Network Game Transfers
- keep golden images by hardware class rather than one image for every possible machine
- use JParrisDesktop / stronger machines for staging/server roles where useful
- use wired Ethernet as the default
- use Gigabit switches even though several older clients only negotiate 100Mbps

Steam local-transfer notes preserved:

- TCP 27040
- UDP 27031-27036 for discovery

Older 100Mbps clients mainly slow setup/file transfer; they do not necessarily prevent lightweight LAN gaming.

## 15. Final position from this conversation

The conversation changed the DadLAN buying strategy in several useful ways.

### Purchase rule

Do not buy a machine merely because it is cheap.

A DadLAN purchase should be:

- confirmed working
- technically above the required floor
- complete enough to use without a major repair
- priced on delivered cost
- preferably seller-backed/returnable

### The AU$89 HP ProBook 11 G2

The AU$89 delivered ProBook 11 G2 was considered a **very good DadLAN purchase** because it combined:

- 6th-gen Core i3
- HD 520
- SSD
- charger
- tested working battery
- working-condition seller description
- warranty/returns
- free delivery

It was materially more sensible than saving AU$10-AU$20 on an untested or defective machine.

### Fleet strategy

The highest-value next steps are:

1. raise the weakest end of the fleet
2. prioritise working ex-business laptops
3. standardise around roughly 6th-gen Core i3/i5 or better for paid purchases
4. aim for 8GB RAM where practical
5. keep donated older Sandy Bridge-class machines when they still serve the game library
6. avoid pouring money into machines that should simply be replaced
